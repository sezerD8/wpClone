# wpClone – WhatsApp Homepage Clone

A front-end practice project that recreates the 2022 WhatsApp website homepage with HTML, CSS and Bootstrap, including a separate mobile layout.

**[English](#english) | [Türkçe](#türkçe)**

> This is a non-commercial learning project. WhatsApp name and logos belong to their respective owner.

---

## English

### Features
- Desktop layout: header, hero section, Business and end-to-end encryption sections, footer
- Dedicated mobile layout (≤ 767px) with a slide-in navigation menu
- Plain HTML/CSS + Bootstrap 5, a few lines of vanilla JS

### Run locally
No build step. Clone the repo and open `index.html` in a browser:
```bash
git clone https://github.com/sezerD8/wpClone.git
cd wpClone
start index.html
```
An internet connection is needed for Google Fonts and Font Awesome icons.

### Project structure
```
index.html            # page markup (desktop + mobile sections)
css/all.css           # imports Bootstrap and the custom stylesheet
css/custom/style.css  # custom styles and media queries
js/script.js          # mobile menu open/close
img/                  # images
```

## Türkçe

2022 tarihli WhatsApp web sitesi ana sayfasının HTML, CSS ve Bootstrap ile yeniden yapıldığı, ayrı bir mobil tasarım da içeren front-end pratik projesi.

> Ticari olmayan bir öğrenme projesidir. WhatsApp adı ve logoları sahiplerine aittir.

### Özellikler
- Masaüstü tasarım: üst menü, giriş bölümü, Business ve uçtan uca şifreleme bölümleri, alt bilgi
- Kayarak açılan menüye sahip ayrı mobil tasarım (≤ 767px)
- Sade HTML/CSS + Bootstrap 5, birkaç satır saf JavaScript

### Yerelde çalıştırma
Build adımı yoktur. Repoyu klonlayıp `index.html` dosyasını tarayıcıda açın:
```bash
git clone https://github.com/sezerD8/wpClone.git
cd wpClone
start index.html
```
Google Fonts ve Font Awesome ikonları için internet bağlantısı gerekir.
